Privacy notice for the AWA MCP server

This notice covers the hosted AWA MCP server at https://agentic-workflow-architecture.web.app/mcp and the AWA plugins and connectors that reach it. It is run by Yannick Huchard, the maintainer of the open-source Agentic Workflow Architecture project.

What the server receives

Only the arguments of the tool your AI assistant calls: the AWA documents it passes (workflows, customer journeys, simulated outputs, business events, an optional brand). The server asks for no account, no key and no personal details. Do not put personal or confidential data in the documents you send; the bundled example is fictional.

What it does with them

  • It validates, shows or simulates the documents in memory and sends back the result.
  • Every tool is read-only. Nothing a document names is executed: no command, HTTP call, model or production system.
  • It stores nothing: no database, no files, no session between calls. It does not write the content of requests to its logs.
  • It does not read your conversation, memory or files beyond the tool arguments, and it shares nothing with anyone.

What the hosting platform records

The server runs on Google Cloud Run in the European Union (region europe-west1), behind Firebase Hosting. Like any web service there, Google Cloud keeps standard request logs: time, address and path, status, response time, IP address and user agent. They do not contain the request body. These logs are used only to keep the service running and to stop abuse, and Google Cloud deletes them after its default retention period of 30 days. Google acts as a processor under the Cloud Data Processing Addendum.

Your AI assistant

The assistant you use (Claude, ChatGPT, Le Chat, Cursor, Gemini CLI or another) decides what it sends to the server and keeps your conversation under its own privacy policy. This notice does not cover it.

Questions and requests

Open an issue in the project's repository. Under the GDPR you may ask what data concerns you and ask for it to be erased; as the server stores nothing itself, only the platform's request logs above can hold an IP address.
